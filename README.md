# Mathew Babu portfolio

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local URL after starting (normally `http://localhost:5173`). Create a production build with `npm run build`.

## Editable content

Update profile URLs, email, portrait, project preview/link fields, skills, and education placeholders in `src/content.ts`. Add approved local imagery to `src/assets/` and point the relevant content field to it.
